Stop all macros is the panic button. It stops everything Lunchpad is running, on every page, including the macro it is in. The action has no settings.

## How it runs

- Every running macro stops, including fader actions and the macro this action belongs to. Actions after it in the same list do not run.
- Every sound Lunchpad plays and any speech stop, even ones started outside a macro.
- A held push-to-talk key is released.
- Programs started with **Stop the program when the macro stops** close.

You do not need a pad for this: right-click any pad and choose **Stop all macros** (it reads **Stop 2 running macros** while something runs), or use **Stop all running macros** in the tray menu.
