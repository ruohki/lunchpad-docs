A button set to **Run alongside** starts a run of its own on every press, so pressing quickly layers the runs on top of each other: a sound plays twice, a countdown runs twice. Restart this macro makes a new press replace the older ones instead. The action has no settings.

<Aside type="tip">
For the plain case, a new press replacing the old one, set the button's **Pressed again while still running** to **Start over** instead: it needs no action. See [Action lists](/guides/action-lists/#pressing-a-button-that-is-still-running). Restart this macro is for the cases that setting does not cover: it stops the runs of every list of the button, and only once the run has reached it.
</Aside>

## How it runs

- It stops every other run of this button that is still going, from any of its lists. The run it is in carries on with the next action.
- Other buttons are not affected.
- The stopped runs end the same way as with [Stop this macro](/actions/stop/stop-this-macro/): their sounds stop, waits end, requests are cancelled.
- Put it first in **When pressed**. Anything before it still runs in parallel with the older runs.

## Example

A sound that restarts on every press instead of stacking:

1. **Restart this macro**
2. [Play sound](/actions/media/play-sound/) `drumroll.mp3`

The same works for a "Be right back" button with a [Delay](/actions/general/delay/) of a few minutes before it switches back: pressing it again starts the timer over.
