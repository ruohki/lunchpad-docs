This action runs the big switches of your streaming app: going live, recording, and the replay buffer that keeps the last moments ready to save.

<Aside type="note">
Switch the integration on first, under Settings → **OBS Studio** or **Streamlabs Desktop**. See [OBS Studio and Streamlabs](/guides/obs-and-streamlabs/).
</Aside>

## Settings

| Setting | What it does |
| --- | --- |
| **What** | **Stream**, **Recording** or **Replay buffer**. |
| **Action** | **Start**, **Stop** or **Toggle** (start when off, stop when running). |

## How it runs

- **Start** on something already running, or **Stop** on something that is off, changes nothing. Streamlabs Desktop checks first; OBS Studio refuses the request, which ends up in the log.
- The replay buffer has to be set up in the app before it can start (in OBS Studio under Settings → Output → Replay Buffer).
- Errors are noted in the log and the macro goes on.

<Aside type="caution">
A pad that stops the stream is easy to hit by accident. Consider putting it in **When held** so it needs a long press, see [action lists](/guides/action-lists/).
</Aside>

<Aside type="tip">
Set **Active while** to **Streaming**, **Recording** or **Replay buffer running** so the pad shows the state. See [buttons](/guides/buttons/).
</Aside>

## Example

A "Go live" button:

1. [Switch scene](/actions/streaming/switch-scene/) `Starting soon`.
2. **Stream, record, replay**: **Replay buffer**, **Start**.
3. **Stream, record, replay**: **Stream**, **Start**.
