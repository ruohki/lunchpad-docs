Something great just happened on stream. Save replay writes the last seconds the replay buffer holds to a file, so you can clip it later. The action has no settings.

<Aside type="note">
Switch the integration on first, under Settings → **OBS Studio** or **Streamlabs Desktop**. See [OBS Studio and Streamlabs](/guides/obs-and-streamlabs/).
</Aside>

## How it runs

- The replay buffer has to be running. Start it with [Stream, record, replay](/actions/streaming/stream-record-replay/) or in the app. If it is not running, the app refuses and the log notes it.
- The file lands where the app saves replays; its length is set in the app.
- Errors are noted in the log and the macro goes on.

## Example

A "Clip it" pad that confirms with a sound:

1. **Save replay**
2. [Play sound](/actions/media/play-sound/) `clip.wav`

Give it an active colour so the pad lights while the macro runs.
